Debian NAS WebUI

控制台状态与入口。主界面在 /，登录后可用全部功能。

已就绪

  • PAM 认证（系统账号密码），会话 8 小时，CSRF 校验
  • 首页 / 共享 / 文件 / 用户 / 存储 / 网络 / 服务 / 日志 / 终端 / 更新
  • 虚拟机：libvirt 创建、启停、快照、磁盘扩容、光驱、网页 VNC 控制台
  • 后端只监听 127.0.0.1:8080，由 Caddy 终止 TLS 并反代

入口

  • 控制台：https://<主机>/
  • 虚拟机控制台：在「虚拟机」页点「控制台」，或 /console.html?vm=<名称>
  • 服务状态：systemctl status debnas-web caddy libvirtd
打开控制台

可选依赖

  • libvirt-daemon-system + virtinst：虚拟机
  • samba-common-bin / smartmontools / podman：对应页面
  • 网页控制台的 noVNC 已内置，无需安装
